QUICK GUIDE

使用说明

从任务提交到结果回放，几步就能完成一次 Agent 执行检查。

快速开始

1
选择一个示例任务

在任务工作台选择结算、支付或库存服务，也可以直接编辑自然语言任务。

2
点击“开始执行任务”

后端根据当前模式执行 Mock 流程或真实模型决策，并将每个步骤保存到本地 SQLite 数据库。

3
阅读诊断结论和执行轨迹

结论区提供中文摘要；轨迹区可以展开原始数据，供开发调试与证据核查。

4
查看回放或运行自动评测

运行记录可用于查看已保存的工具结果；评测中心会检查 3 个固定场景。

当前版本边界

  • 默认本地 Mock 模式无需密钥；设置 AGENTTRACE_MODE=llm 后使用真实大模型。
  • 结算、支付、库存服务的状态、日志和部署信息均为合成数据。
  • 回放展示的是历史工具结果，不会重新执行任务。
  • 本地 API 尚未配置身份认证，仅建议用于本机开发和演示。
  • API Key 仅在服务端环境变量配置，浏览器不接收密钥。自动评测仍为固定 Mock 基准。
