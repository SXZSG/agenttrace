# Code of Conduct

AgentTrace aims to provide a respectful, constructive environment for contributors of all backgrounds.

Examples of expected behavior include being considerate, sharing reproducible technical feedback, accepting good-faith criticism, and focusing discussion on the work rather than the person.

Unacceptable behavior includes harassment, discriminatory language, personal attacks, publishing private information, and deliberately misleading benchmark or security claims.

Project maintainers may edit, remove, or decline contributions that violate these standards. For sensitive concerns, contact the repository owner privately through GitHub rather than posting personal or security-sensitive details publicly.
