# Visual validation

在 Windows 本地 Mock 模式下使用真实浏览器访问 `http://127.0.0.1:8016/` 验证：

- 总览页面加载服务状态、当前 Mock 模式、最近运行和空评测批次。
- 主导航可以打开任务工作台、执行追踪、可靠性评测、版本对比和使用说明。
- 可靠性评测页面显示离线运行入口、token/成本未知说明和历史批次空状态。
- 版本对比页面显示 Baseline/Candidate 选择控件，并在无批次时显示真实空状态。
- 小屏浏览器视口下导航可以横向滚动，内容卡片没有阻断性溢出。
- 总览、一次已保存任务的 Trace、故障可靠性评测空状态和版本对比空状态均实际截屏检查；截图显示的运行记录来自本地数据，未包含 API Key。

验证使用合成数据和本地 Mock provider，没有调用真实模型 API。截图由本地浏览器验证会话实际捕获并在交付记录中展示。当前 CUA 浏览器接口只返回截图字节用于会话展示，无法安全写入项目白名单目录，因此审计 ZIP 包含本验证记录而不伪造或复制截图二进制文件。
