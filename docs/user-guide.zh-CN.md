# AgentTrace 中文使用说明

## 1. 启动

在 Windows PowerShell 中进入项目目录并启动 API：

```powershell
Set-Location ".\agenttrace"
.\scripts\run_api_windows.ps1
```

保持该 PowerShell 窗口运行。浏览器打开 `http://127.0.0.1:8000/`，即可使用中文工作台。

如果提示缺少依赖，先执行：

```powershell
.\.venv\Scripts\python.exe -m pip install --index-url https://pypi.org/simple -e ".[dev]"
```

## 2. 提交任务

在“任务工作台”中选择“结算服务异常”“支付服务巡检”或“库存服务超时”，也可以直接编辑任务描述，然后点击“开始执行任务”。任务中包含 `checkout`/“结算”、`payments`/“支付”或 `inventory`/“库存”时，Mock 提供器会选择相应的模拟场景。

## 3. 查看结果

结果区包含：

- **诊断结论：** 中文摘要、当前状态、主要证据、近期变更和建议。
- **执行过程：** 按时间顺序展示任务事件与工具调用状态。
- **原始事件数据：** 在对应步骤中展开，用于开发者核查结构化 Trace。
- **执行回放：** 展示已保存的工具调用结果。回放不会重新运行模型或工具。

## 4. 运行自动评测

打开“自动评测”，点击“运行评测”。系统会执行 3 个固定模拟场景，并检查工具顺序与关键证据项。评测结果用于验证当前确定性流程，不代表真实模型准确率或生产任务成功率。

## 5. 运行记录

“运行记录”会显示 SQLite 中保存的最近任务。选择某条记录可以重新查看诊断结论、事件轨迹与回放结果。

## 6. 开发者 API 文档

`http://127.0.0.1:8000/docs` 是 FastAPI 自动生成的开发者接口文档，不是普通用户主界面。建议日常演示从中文工作台进入。

## 7. 当前限制与安全提示

- 默认提供器是确定性 Mock；真实模型配置见 [Phase 2 配置说明](llm.zh-CN.md)。工作台会显示当前模式和历史运行各自的模型。
- 所有服务状态、错误日志、部署记录和操作手册均为合成数据。
- API 尚未配置身份认证，仅建议在本机使用；不要将其暴露到不受信任的网络。
- 不要输入真实凭据、API Key 或生产环境机密信息。
- 诊断结论仅用于演示和工程验证，不能作为真实生产环境的运维决策。
